# Frontend MVP

Phase 5 provides a responsive React workspace at `http://localhost:3000` with:

- local demo sign-in;
- live portfolio metrics and ingestion activity;
- passport registry, detail, RDF downloads, QR, validation, and version creation;
- Turtle/JSON-LD validation with field-level results;
- CSV/JSON ingestion with job history and quarantine details.
- semantic quality scores, trends, vocabulary adoption, ontology versions, and
  supplier completeness with graph-backed filters.

All data pages show loading, empty, and API error states. The demo session is
device-local navigation only; API authentication and role enforcement remain
reserved for future security hardening.
