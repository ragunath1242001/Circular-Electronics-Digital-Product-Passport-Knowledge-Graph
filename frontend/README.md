# Frontend

React, TypeScript, and Vite workspace for the dashboard, passport, validation,
ingestion, SPARQL, Cytoscape graph, observability, cited reports, and governance workflows. Sign-in is an
explicitly local demo session; production identity verification is outside this MVP.

```powershell
cd frontend
npm install
npm run dev
```

Run checks with `npm run typecheck`, `npm test`, and `npm run build`.
